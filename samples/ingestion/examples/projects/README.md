# Fabricated reference projects

`robotelier` covers humanoid robots, manufacturers, capacity, technical progress
and manufacturing constraints in English. `myprojects` covers repositories,
development, pull requests/issues, contributors, documentation and organization
activity in Italian. Both use Europe/Rome. Daily/weekly clocks are06:00/Sunday08:00
and07:00/Sunday07:00 respectively. Schedules are disabled.

All names, records, accounts and repositories are synthetic. The example server
and UUIDs are placeholders. Tests rebind them to disposable protected spaces and
mock remote responses. No real WikiPlant instance has been read or migrated.

`manifest.yml` is a validated C0 manifest template; `topics.json` supplies synthetic
tracking approvals for tests. `sources.yml` is the independent worker's bounded
source selection. An actual job needs its own existing C0 OAuth configuration,
explicit target binding and Admin source approval. Never copy a test approval as
real user authorization. The local inputs are public-safe fabricated text.
