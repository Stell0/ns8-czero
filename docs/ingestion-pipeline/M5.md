# M5 — current structure and section chunks

This isolated successor depends on accepted M4. The complete canonical body
remains authoritative. Structure is bounded derived metadata on that document,
with source-character spans for headings, parent sections, typed blocks and
explicit local references. No generated summary or ancestor text is inserted
into evidence. Markdown fences precede heading recognition; DOCX headings use
original paragraph styles under the existing isolated parser safeguards.

Queued publication selects `sections-v1` by default and accepts an explicit
`fixed-v1` comparison profile. Both profiles retain existing chunk count/size
limits and exact body offsets; older pending manifests and ordinary extraction
keep fixed chunks. Store structure/profile with the new complete generation in
the publication transaction. Existing documents get no backfill or changed IDs.
Retirement deletes derived metadata with the body. A deliberate later reindex
must publish a fresh generation and retire old exact citations with 410.

Acceptance checks exact roundtrip, Markdown fences/headings/tables/code/lists,
DOCX styled headings, PDF pages, Unicode offsets, bounded oversized blocks,
protected-space authorization and replacement cleanup. A frozen deterministic
prerequisite/procedure comparison measures evidence coverage and bytes separately
from model answer quality. Full independent packages and native gates remain.
