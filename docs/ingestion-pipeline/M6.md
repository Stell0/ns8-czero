# M6 — optional local page OCR

This isolated successor depends on M3–M5 acceptance. Only an explicit instance
setting selects the registered local Tesseract adapter for PDF pages whose
ordinary text parser reports `unsupported_scan`. Readable and genuinely blank
pages keep ordinary extraction. Disabled/unavailable OCR yields a safe explicit
failure and never triggers a remote request. No cloud adapter is registered.

Freeze the renderer/engine binaries, selected installed language-model hashes,
normalization and bounded raster settings in the run manifest. Support only
bundled English/Italian language choices; no requests choose commands, paths,
models, URLs or credentials. Verify the same backend before executing a unit.
Run fixed commands in an isolated process group with the existing 25-second
parent deadline, 512 MiB address-space and CPU limits, bounded raster/output and
private temporary files. Kill the complete group on timeout. Child environment
contains no database, OAuth or provider credentials.

Persist page provenance and observed confidence/word counts with a checksum;
copy bounded provenance to the new current document and clear private staging.
No confidence is invented for ordinary pages; no provider cost is inferred.
Retry only failed units and retain exact page locations/latest-only cleanup.

Tesseract is Apache-2.0; Debian Poppler is GPL-compatible with this GPL-3.0-or-later
application. Keep installed copyright notices, package inventory, image audits
and scans. Primary backend references: [Tesseract manual](https://tesseract-ocr.github.io/tessdoc/)
and [command/TSV contract](https://tesseract-ocr.github.io/tessdoc/Command-Line-Usage.html).
Independent Core still installs without these optional system tools; opting in
without a backend fails explicitly. Actual local, wheel/archive, image and native
synthetic scan evidence is required before acceptance.
