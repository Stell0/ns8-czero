Implementation and deterministic/disposable acceptance are complete; model/held-out
answer quality remains open by operator decision. Building on accepted M1–M9,
this implementation provides reproducible measurements, destructive disposable

## Extraction measurements

Run `scripts/benchmark-ingestion.py` with an explicit loopback PostgreSQL
administrator URL in `CZERO_EVAL_DATABASE_URL` and a new private `--output`.
The runner creates/drops only its own randomly named databases; measurement
children refuse every other database name. Every input is checked against the
frozen M0 original/expected-text manifest before execution. No model is called.

Compare the legacy whole-document handler with one/two/four queued workers,
each with disabled result caching and with a prewarmed current owner in the same
space. Rotate arm order between repetitions. Default five repetitions report
median and nearest-rank P95; a one-pass `--smoke` result is explicitly exploratory.
"Cold" means disabled output reuse, not flushed operating-system/disk caches.
Continuous bounded one-shot drains exclude the native timer's wake-up delay.

Record upload, manifest/preflight, extraction/publication and verified end-to-end
time, CPU seconds, 50 ms sampled process-tree RSS, explicitly labelled lifetime
RSS, SQL statement count/aggregate elapsed time, database/table size and raw
asynchronous PostgreSQL block/tuple/IO counters. These are observations, not a
fabricated CPU quota, exact memory peak, synchronous IO attribution or billing
estimate. Local OCR reports no provider charge; unavailable cost remains null.
Whole text/hash, character count, source locations and every search-chunk span
must match the independent canonical originals. Tiny inputs remain in the matrix.
