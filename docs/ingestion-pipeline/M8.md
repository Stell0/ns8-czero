# M8 — exact selective context

This isolated successor depends on M5 acceptance; M7 is optional. Add read-only
`source_document_outline_get`, `source_document_sections_get`,
`source_document_references_get` and `context_bundle_get` over the existing
Reader/c0:read operation catalog. Discovery reflects actual installed Core
capabilities; a released older Core retains its existing catalog and behavior.
No new scope, client identity or consent is introduced.

Each result binds the selected space, canonical logical document, exact current
revision, full-body hash, source spans and existing chunk citation handles.
Section/reference IDs are local to that required revision. Outline can discover
the current revision; all subsequent selection requires it. Expired generations
return 410. Invalid/denied selections abort, without Shared/current fallback.

Use persisted current structure when available; derive bounded metadata in memory
for legacy/current multipart bodies without writing or reindexing. Resolve only
explicit unambiguous local anchors. Never fetch a reference URL or execute source
instructions. Whole-document reads remain available through their existing API.

A closed plan selects at most five documents and twenty sections/references in
caller order, in one authorized repeatable-read snapshot. Replies explicitly mark
selected evidence as incomplete, report omitted oversized/unresolved selections,
and enforce serialized UTF-8 context-payload bytes (4–64 KiB, excluding transport envelopes) and estimated tokens
(256–16384, UTF-8 bytes/3 rounded up). This estimate is not a provider token count;
external agents retain their own tokenizer/message budget. No generative model,
ranking inference or automatic broadening runs inside C0.

Verify actual REST and current/legacy SDK reads, contracts/safety hints, scope and
protected-space denial, revocation, replacement races, malformed plans/bodies,
Unicode offsets, multipart source-sync boundaries and bounded response sizes.
Synchronize public reference/guidance and instance-bound research instructions;
verify generated package content and real disposable operations. Model answer
quality remains separately measured rather than inferred from fewer bytes.

Legacy metadata derivation retains the existing extracted-body ceiling of
2 MiB / 1,000,000 characters and a bounded line/section inventory. Larger existing
logical parents retain their complete legacy reader; selective derivation returns
explicit `too_large` rather than changing limits or silently splitting a request.
Outline `view=blocks` exposes exact page/paragraph/table/code IDs as bN selections.
