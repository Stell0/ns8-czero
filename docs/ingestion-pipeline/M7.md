# M7 — current-owned, space-scoped reuse

This isolated successor depends on M2–M6 acceptance. There is no new body store:
reuse validated successful live-staging units or exact slices of a current
published document. Cache lookup binds selected space, original SHA-256, media,
partition/normalization/engine/model/settings profile, ordinal and locator.
Version/generation lease identities remain separate from reusable input identity.

Current documents and their payload-free unit hashes own published reuse. Live
runs own private output only until their existing expiry. Check current native
actor/space authority and generation on staging owners; current-source ownership
and deletion on published owners. Recheck the owner and checksums in the target
completion transaction. A retired or corrupted owner causes recomputation,
never historical resurrection or unauthorized publication. Existing FK cleanup
removes ownership on retirement; there is no permanent content-addressed archive.

Reuse is optional for controlled cold/warm comparisons. Preserve original checks,
lease fencing, result/output caps, atomic assembly and fresh exact generation IDs.
Count actual successful reused units/bytes and misses; existing measured run/wait
counters remain wall times, not fictional avoided CPU or monetary cost. No cloud
provider reports billing in the local-only implementation.

Acceptance covers current and live-staging hits, engine/config misses, exact
readback, failed sibling recovery, replacement between lookup and commit, expired
owners, deleted/revoked/protected-space boundaries and A→B→A fresh IDs/410.
No old documents are automatically reindexed or copied during migration.

## Local checkpoint

Cache, queue, format, OCR, native configuration and backup controls pass 110
cases. These include real current/blank-page reuse, private staging, ownership
retirement between lookup and commit, expiry/revocation, current corruption,
profile changes, actual bilingual OCR recomputation and A→B→A fresh identities.
Independent package and full/native acceptance remain required.
