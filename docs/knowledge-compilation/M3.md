## Refined implementation contract

Keep the six coordination tables. Schema0034 adds metadata fields and indexes,
not another knowledge store. Existing source and snapshot rows receive private
monotonic publication markers, assigned transactionally under the content mutex.
The sequence orders publications independently of ingestion timestamps and UUIDs. Public cursors expose a space-bound cutoff hash rather than global publication ordinals; unrelated spaces cannot reveal their activity counts.
Completed multipart snapshots are logical originals; physical parts never become
independent compilation units. A failed replacement retains its complete current
generation. Private markers never enter ordinary source/object API responses.

An inventory cursor is a non-executable row in the existing runs table, separate
from invocation leases and budgets. Persist a publication cutoff and keyset cursor;
finish that sweep before starting a catch-up sweep. Reconcile previously observed
logical IDs in bounded pages after enumeration; disappearance is established by
an exact current read, never absence from a partial list. Inventory completion is
not semantic coverage. High-fanout assessments return target_overflow for explicit review rather than claiming that omitted targets were revalidated. Restart, late insertion, changes behind the cursor and
multipart shrink must remain discoverable. Metadata scanning may repeat; unchanged
source/profile/assessment inputs must not cause repeated inference or Wiki writes.

Source assessment tasks are explicitly distinguished from knowledge proposals.
They reserve document/model budgets and cannot publish a Wiki page. External
reasoning reads whole originals or records unread-context deferral, finds existing
concepts, and creates ordinary canonical-topic proposals using M2. Completing an
assessment records bounded reviewed character ranges, child identities and fixed unresolved findings. Success
requires fresh originals and actual verified child publications; pending, failed,
contradictory or partially read work remains visible without claiming compilation.
No-change is a justified external assessment, never a discovery shortcut. Partial originals retain merged reviewed ranges; genuine progress creates a linked bounded successor after its child changes settle. No-progress and uncertain work remain held. Settled expired work can transfer to a fresh invocation, retaining attempts; unknown model calls require reconciliation in their original run. A recovered project host also advances the compiler fence.
Dependencies retain exact retired identities and stale status; revalidation may
publish new support only through M2, never silently replace an expired citation.

All mutations require enabled policy, current Editor and read/write scope, live
fence and expected run/task/cursor revisions. Concurrent workers converge on stable
assessment identities. Each invocation remains bounded by M1 deadlines, retry caps,
document/page quotas and model reservation accounting. Read operations create no
state. Source text is untrusted data; no source instructions or raw queries enter
coordination metadata.

Daily/weekly invocations in configured projects bind the existing project run and
configuration. Intersect project and compilation limits and restrict automatic
source discovery to approved tracked connectors. Existing project phases, reports,
audit and semantic review APIs remain authoritative. Store compiler run IDs in
report content/metadata, not the unchanged project resource-reference resolver.
Ordinary spaces use the same compiler and shared bounded rotating Wiki selector.
Weekly completion means the selected batch was reviewed, never whole-corpus review.
No duplicate scheduler or project initialization is allowed.
