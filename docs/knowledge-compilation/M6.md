Implementation starts from original main
`537207b228f0fb2b2d8f131e0187ad5d4db54d32`, after M5's protected regular
merge in PR105. Its exact-source full gate passed. The separate M5 main run

## Frozen contract

Reuse the existing paired PostgreSQL fixture, authenticated MCP read boundary,
isolated pinned Codex driver, source-only builders, private label audit and
single-use development/validation/sealed comparison. Both arms retain identical
original logical/physical identities, generations, hashes, applicability metadata
and read catalogs. Construction sees current originals, never questions, labels,
answers or retrieval failures. Public synthetic regression probes are exposed
controls, not sealed quality evidence.

Add an explicitly selected compiler publisher to the benchmark. It maps the
existing source-only navigation proposal to Core's production navigation_plan,
compile_plan and verify_pending helpers. Only the invocation-owned disposable
fixture may enable its test policy. Its queue-only publication requires a separate
source-based review bound to the exact corpus and plan hashes. Uncertain synthesis
remains unverified and is published only with exact-plan approval. This measures
reviewed external construction and real compiler publication; it does not pretend
that offline builder usage was reserved against a later server task. Provider
usage stays in the experiment ledger. M5's actual hosted workflow and the M1–M5
regression suites supply separate inference-accounting and recovery evidence.

A durable private publication journal records intent before I/O. Repeated settled
publication verifies actual saved targets and citations without rewriting them.
Unknown writes stop; saved task publications reconcile through Core readback.
Authored changes, expired citations or source drift stop the comparison. No
production policy, data, permissions, project, deployment or schedule changes.

Add a separate answer-audit command. Reviews bind the exact frozen question,
final answer and actual observed evidence. Missing or unknown judgments remain
unreviewed. Report analyst provenance, reviewed denominators, answer correctness,
unsupported assertions and limitations separately from deterministic evidence,
Recall@K/MRR, applicability and disposition. The producing/retrieving model cannot
attest its own correctness. No automatic entailment or verified-truth flag.

## Study and stop rules

Freeze default protocol thresholds before inference: complete evidence >=0.80,
>=0.10 absolute gain (or the existing high-baseline efficiency alternative),
clarification/abstention >=0.80, no invalid credited citations, unauthorized writes,
source drift or known product/version errors, <=12 mean tool calls, <=180-second
P95 and <=200,000 observed mean tokens. Preserve all failures and report unmet
quality thresholds; a completed comparison is not accepted improvement.

Use the exact available requested/reported model identity. Luna unavailability
blocks a Luna study; no silent model substitution. Keep monetary cost unknown
unless actually reported. Corpus and selected-page coverage use actual SQL source,
task and dependency counts; bounded completion never means whole-corpus coverage.
No tuning after validation or sealed results. Missing model access, exhausted
budgets, leaked labels, unauthorized movement or stale support stops that study.

Read-only live inspection checks actual membership, capabilities, policy, current
source readiness, existing approved test pages and original citations. A bounded
private original copy and disposable compilation requires separate authorization;
ticket material requires its own explicit selection. Prior approval of six writes
in an existing namespace does not authorize additional production mutations.
Private source bodies, identifiers, questions, credentials and evidence stay
outside Git. Public reports contain sanitized aggregates only.

## Acceptance checklist

- [x] Latest original main isolated; M5 exact-source gate accepted.
- [x] Contract refined before implementation; boundaries and thresholds retained.
- [ ] Existing complete synthetic PostgreSQL/security/recovery matrix passes.
- [ ] Compiler publisher tests cover real publication/readback, repeated unchanged
      execution, source replacement, uncertain writes and held review.
- [ ] Answer audit rejects changed/missing/duplicate evidence and reports coverage.
- [ ] Frozen matched real-model A/B comparison, source-based label/answer review,
      actual metrics, usage, latency and explicit unmet thresholds recorded.
- [ ] Authorized representative private-source dry-run/disposable acceptance, or
      the missing authorization/capability recorded as an incomplete gate.
- [ ] Installed package/archive, migration and native acceptance on exact source.
- [ ] Complete diff/privacy review, focused upstream PR and actual C0 merge gate.

Core, schema, runtime, dependency locks, registered app identity and scopes do not
change. No Core publication, production rollout or persistent scheduler activation
is part of M6. A failed quality or private acceptance gate remains open even if
the reusable test/report tooling is accepted.
