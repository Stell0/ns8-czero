## Refined contract

The answer is delivered before feedback starts. The external host explicitly
attests that delivery; the helper accepts no answer, user query, conversation,
benchmark question/ID/label or free-form explanation. If a host cannot continue
after delivering an answer, it skips feedback rather than delaying the answer or
claiming that later execution is installed. No background server task is implied.
An explicitly read-only request, missing actual-scope capabilities or no material
source-backed signal performs no learning I/O. Most episodes take this no-change
path; enabled feedback never requires another user prompt.

The bounded observation has only a canonical source-derived topic key, fixed
retrieval reason, source-derived label, up to three exact current logical source/
chunk selections and an optional current Wiki identity. It uses the existing
proposal schema/identity rules. Resolve aliases and semantic equivalence externally;
a different title, language or query wording cannot establish a new concept. Prefer
an existing target/task identity. Unknown fields fail closed; source text remains
inert data. Do not encode queries, answers or evaluation labels in topic keys,
source labels or replay identities.

The optional external helper first reads spaces_get and requires an effective
Editor/Admin role in the exact selected space, even for a global Editor. It then
checks the selected-space policy and feedback flag,
allowed page targets, current original bindings, current Wiki and equivalent SQL
tasks. A candidate for a new concept with matching Wiki results is deferred for
explicit concept resolution. Changed/expired source or target bindings defer the
episode; never substitute a fresh citation. Inspect a bounded task page before
queueing. Reuse matching active/terminal outcomes through fresh task readback;
incomplete comparison defers. Concurrent equivalent proposals converge through
M1's trusted transactional deduplication.

At most one metadata-only `origin=retrieval` proposal is submitted. Both queue-only
and automatic-supported policies may queue; publication remains the common M2/M3
workflow with all existing validation, classification, budgets and readback.
Contradiction/applicability findings retain existing review holds. The step never
runs a new model, claims compiled knowledge or publishes ordinary Wiki/bundle
writes. Existing retrieval model caps remain authoritative for any separately
requested reasoning invocation; the helper consumes none of those requests.

Feedback has a hard five-second maximum and at most seven API calls, no corpus scan,
no provider call and no automatic retry. Retain an opaque stable request key before
I/O. Transport/tool/readback failure after submission is uncertain and keeps its
recovery identity; inspect current tasks before retrying the unchanged request.
Failure before submission defers. Errors return fixed codes only and never replace,
retract or block the already delivered answer. A saved proposal is pending work,
not proof of compilation or factual correctness.

Reader-only accounts and connections without Write see ordinary research
guidance only. A global Editor with only Reader access in the selected protected
space stops at spaces_get without any mutation call. The
optional guidance is included using actual authorized capability descriptions,
not SDK discovery that may list tools requiring more scopes. Server operations
still recheck current persisted roles, exact space/grants, actual scopes, policy,
source identities and queue cap. Discovery grants no authority; learning does not
request broader scopes or change policy.
