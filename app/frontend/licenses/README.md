# Bundled license notices

The frozen npm package `@headlessui/vue@1.7.23` omits its license file.
`headlessui-vue-1.7.23.txt` is copied unchanged from the package's reported
[Git source](https://github.com/tailwindlabs/headlessui/blob/2a46945675c4b52d7b73e1ed612cf70605e2b576/LICENSE).
The build uses this exact-version fallback; other missing bundled licenses fail.
All other bundled module notices are collected from their installed package
roots. Local Poppins and Markdown parser notices accompany their public assets.
